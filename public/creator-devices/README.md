# iPhone frame

`iphone-16-pro.png` is the existing iPhone 16 Pro Black Titanium frame distributed by [Mockify](https://github.com/Mecury-Labs/mockify), sourced there from Apple Design Resources. Screen geometry comes from its published `iPhone16Pro` device configuration (1350 × 2760). This is a device presentation asset, not an endorsement by Apple.

Source: https://github.com/Mecury-Labs/mockify/blob/main/public/devices/iPhone%2016%20Pro%20-%20Black%20Titanium.png
