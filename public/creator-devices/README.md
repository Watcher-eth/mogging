# iPhone frame

`iphone-16-pro.png` is the existing iPhone 16 Pro Black Titanium frame distributed by [Mockify](https://github.com/Mecury-Labs/mockify), sourced there from Apple Design Resources. Screen geometry comes from its published `iPhone16Pro` device configuration (1350 × 2760). This is a device presentation asset, not an endorsement by Apple.

Source: https://github.com/Mecury-Labs/mockify/blob/main/public/devices/iPhone%2016%20Pro%20-%20Black%20Titanium.png

## Handheld report photo

`handheld-night.png` is a project asset generated with the built-in image generation tool. Prompt: photorealistic vertical nighttime parked-car image, city bokeh, natural hand holding a straight-on black phone with a blank gray screen, quiet dark space above for branding, fingers clear of the display, no logos or text. The report, creator portrait, scores and branding are rendered in code; none are baked into the photo. Screen coordinates in `phone-report.ts` are calibrated to the original 941 × 1672 image.
