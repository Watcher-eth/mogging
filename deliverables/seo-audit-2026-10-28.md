## Live technical audit

The robots.txt and sitemap.xml endpoints also returned HTTP 200. Homepages have nine alternate-language links. Both English guides have Article and BreadcrumbList structured data.

The sitemap contains no lastmod dates. Use real content-update dates if these are added; do not regenerate every date on each request. The non-www HTTPS homepage currently uses a 307 redirect to www; prefer a permanent host redirect after checking domain settings. HTTP-to-HTTPS redirects use 308.
