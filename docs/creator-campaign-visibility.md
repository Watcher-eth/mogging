# Creator campaign visibility

Prepared locally; no live campaign, submission, payment or database changes have been applied.

In **Admin → Creators → Campaigns → Edit → Creators**, choose all creators, only selected creators, or everyone except selected creators. Search by name or social handle and select the accounts. Save changes to apply the audience. Published/ended campaign listings, campaign social proof, support campaign reads and new submissions enforce visibility on the server. Public link previews omit campaigns with custom audiences. Existing submissions retain their terms, earnings and rereview history.

## Release when authorized

1. Apply the additive migration: `bun run db:migrate --only 0064_creator_campaign_audience`.
2. Deploy the updated portal code and verify the admin campaign editor.
3. Preview assignments: `bun run scripts/admin/add-detailed-analysis-variant.ts`.
4. Apply assignments: `bun run scripts/admin/add-detailed-analysis-variant.ts --apply`.
5. Check campaign visibility for each assigned account and an unrelated creator. Confirm their existing submissions remain available with saved terms.

Do not create the published variant before the updated code is live: previous code does not enforce campaign audiences.

## Admin payout review

The admin Earnings tab calculates from each submission’s saved campaign terms. The displayed campaign name and saved-rate label identify which version applies. Approvals recalculate on the server from the same saved snapshot; payment scheduling uses the saved approved earnings and deducts previous payments. No calculation is selected by creator name or a shared creative-format ID.

Maximum-audience rates: original 50K / 100K / 300K = $40 / $70 / $120; MGC = $30 / $65 / $65. MGC has no 300K milestone. Audience tiers still apply, and rereviews preserve previously earned amounts.

Payout regression checks: `bun test lib/admin/submission-review.test.ts lib/admin/submission-payout.test.ts`.
