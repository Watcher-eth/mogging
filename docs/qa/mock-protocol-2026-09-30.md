The third CTA Studio tab generates seven days without a photo upload. Focus options follow mobile report categories. Task copy, focus ranking, time slots, task-count rotation, card colors, and layout measurements were ported from `mogging-mobile/src/screens/reports-screen.tsx`. Native SF Symbols are generated by `scripts/creator-protocol-symbols.swift`.

Browser verification used the local Next.js dev server and mocked API responses, with no account writes:

- Generated all 11 focus areas and verified seven selectable days.
- Checked independent completion states per day, task title edits, and task detail sheets.
- Verified keyboard navigation between all three generator tabs.
- Verified 375px viewport with no horizontal page overflow.
- Exported desktop and narrow-screen PNGs at 1170 × 2532.
- Exported a seven-day MP4; ffprobe confirmed H.264, 1170 × 2532, 14 seconds.
- No browser page errors.

TypeScript, targeted ESLint, and 38 creator protocol/report/export tests passed.

The app's iOS-native tab bar is represented with its labels and SF Symbols in the browser; native system glass rendering remains platform-specific. This is a local creator mock and does not create or complete a real mobile protocol.
