## New motion sequences

These additions are separate from the earlier mirror/pair/loupe/card treatments. The examples use the same sample subject so changes in the animation are easier to compare.

| Sequence | Actual state change | Evidence and limits |
| --- | --- | --- |
| Landmark spans transfer | Three source-image bands separate, settle and project into length-preserving bars. | Measured photo landmarks. Available face-mesh forehead points are not presented as a detected hairline. |
| Defocused chapter | The portrait defocuses behind its spoken topic, then resolves to the same source. | The title comes from the exact narration. |
| Rollover deck | The active view leaves the top of the stack and the next real view becomes active. | Requires three different real sources and their spoken view anchors. |
| Example constellation | Circular portraits move around a shared center and the spoken view enlarges as it takes the focal position. | Same requirements as the deck. The orbit is an adaptation. |
| Visibility sweep | The camera moves toward the forehead while a curved masking edge crosses the actual region. | An occlusion diagram. It does not generate hair or an edited photograph. |
| Axis tension | Opposed dimension arrows draw outward and smoothly change orientation when the narration switches from width to height. | Registered outline only. No beauty scores or clinical dimensions are inferred. |
| Contour construction | The outline builds from measured vertices, then transfers into a separate proportion-preserving radial diagram beside the portrait. | The diagram uses the actual outline. It never assigns an unverified shape classification. |
| Source excerpt | A source-first document surface enters, unfolds its supported excerpt and highlights its lines in sequence. | Uses an approved primary-source claim and preserves the DOI. |
| Source unframing | Credited source footage enters in a social window, then expands as its chrome recedes. | Supplied, usable footage only. Its native resolution must support the enlarged stage. |
| Feature match camera | The same portrait moves through two feature crops with a shared camera and a brief registration crosshair. | Both targets require distinct spoken anchors and valid geometry. |
| Deformation lattice | A native resize cursor picks up a local handle. The visible lattice and source pixels deform together, then the lattice leaves. | An original extension of Qoves' cursor-driven editing language. Explicit supported edits only; the same warp drives the pixels and grid. |

The new sequence IDs are registered in the existing editorial schema and renderer. Automatic direction keeps source identity, word anchors, authored edits, score callouts and closing report requirements authoritative. Visual variants continue to reuse the recorded audio.
